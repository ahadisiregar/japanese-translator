# Japanese Translator

A static website that translates Japanese to English using the free [MyMemory](https://mymemory.translated.net) API.

## Run

Open `index.html` in a browser, or serve the folder: `python3 -m http.server` and visit http://localhost:8000.

Features: auto-chunking of long text, copy, text-to-speech for both languages, dark mode, mobile layout.
